# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

**Preferred:** Enable [GitHub Private Vulnerability Reporting](https://github.com/Alinxus/whisper/security/advisories/new) so researchers can submit findings privately.

**Alternative:** Open a GitHub issue tagged security.

We aim to acknowledge reports within 48 hours and provide a fix within 30 days.
